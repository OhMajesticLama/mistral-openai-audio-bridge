# Roadmap

The roadmap tracks themes and milestones. It is intentionally coarse:
specifics live in stories. Update this when a milestone is reached or a
theme changes direction — not on every story.

## Themes

Themes are long-running concerns that span multiple stories. Each
theme groups related work and outlives any single milestone.
